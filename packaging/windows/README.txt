Nonius — контроль версий для CAD-моделей
=========================================

Установка не нужна: nonius.exe — один файл, OpenCascade и среда Visual C++
уже внутри него. Ставить OpenCascade или Visual C++ не нужно. Распакуйте архив
в любую папку, например C:\Nonius, или просто скопируйте nonius.exe куда удобно.

nonius.exe — программа для командной строки. Двойной щелчок покажет только
подсказку. Работать с ней так: откройте папку с nonius.exe в Проводнике,
щёлкните в адресной строке, наберите powershell и нажмите Enter, затем
введите .\nonius.exe --help

Ещё понадобятся:
  - Git для Windows: https://git-scm.com  (Git LFS идёт в комплекте)

Чтобы команда nonius работала из любой папки, добавьте папку с nonius.exe
в PATH: Пуск → «Изменение переменных среды» → Path → Создать.

Быстрый старт (PowerShell или командная строка):

  nonius init C:\Проекты\станок --name "Станок"
  cd C:\Проекты\станок
  nonius import "C:\модели\кронштейн V1.STEP" --part кронштейн
  nonius commit кронштейн -m "Первая версия"
  nonius import "C:\модели\кронштейн V2.STEP" --part кронштейн
  nonius diff кронштейн                  что изменилось: объёмы, добавлено, убрано
  nonius render кронштейн -o изменения.png   картинка: зелёное — добавлено, красное — убрано
  nonius commit кронштейн -m "Что и почему изменено"
  nonius log кронштейн                   история версий

Проверить, что геометрия включена:

  nonius modules      в списке должны быть step-occt, geometry-occt, highlight-occt
