# Как читать чужие форматы честно: уроки cadmpeg

Принципы и практики, которые стоит перенять Nonius при чтении `.sldprt`,
STEP и при сравнении форм. Читать, прежде чем менять `nonius-sldprt`,
добавлять новый читатель формата или новую точку `ShapeGlance` /
`GeometrySource` / `Comparator`.

Записано 13.11.2026 по исходникам cadmpeg, коммит `a62e55e` (пути ниже — от
корня их репозитория). Это пересказ, а не правила Nonius: что из этого
принимаем — решаем отдельно и записываем в `AGENTS.md` / `ARCHITECTURE.md`.

## 1. Третий исход: «частично, вот что потеряно»

У cadmpeg чтение не бывает «всё или ошибка». Результат — модель плюс
**список потерь**.

- Главное правило `AGENTS.md:3`: декодер читает всё, что позволяет знание
  формата. Если толкований несколько, берёт самое вероятное и записывает
  потерю с названием допущения. Выбросить значение, которое можно прочитать,
  — регрессия, даже если выброс записан.
- У каждого кодека свой перечень `*LossCode`
  (`crates/cadmpeg-codec-sldprt/src/loss.rs`). Запись создаётся только
  вызовом `code.note(msg)`. Строка вида `семья.деталь` — устойчивый контракт,
  из кода выводятся серьёзность и «строгий порог»
  (`crates/cadmpeg-ir/src/report/loss.rs:555`).
- Общая таксономия потерь (`GeometryNotTransferred`, `CarrierAxisInferred`,
  `SourceDialectUnverified`…) — `crates/cadmpeg-ir/src/report/loss.rs:75`.
- Строгий режим отказывает в одном месте — в обёртке `Codec::decode`
  (`docs/architecture.md:156`). Свои «отказы» в кодеках запрещены.
- Неизвестное не роняет чтение: запись сохраняется как непрочитанная
  (opaque), а выбрасывается наименьший зависимый кусок с известными
  границами, а не весь файл (`docs/architecture.md:41-43, 100`).
- Отказ — только по структуре. Неизвестная версия не повод отказать: она
  читается по ближайшей известной грамматике с пометкой «не проверено»
  (`docs/architecture.md:108`).

**Для Nonius.** Третий исход — «вот форма, но такие-то грани не
прочитаны» — прямо отвечает на вопрос, когда звать SolidWorks: есть потери
выше порога → деталь спорная. **Сделано** (PR #27): `nonius_core::design::Partial`
со списком пропусков `Gap`; так отвечают `DesignSource::read_design` и
`ShapeGlance::glance_partial`, контракт проверяет согласие со строгим
`glance` (`docs/ARCHITECTURE.md`, «Третий исход чтения»). `GeometrySource`
пока по-прежнему «всё или ошибка».

## 2. Значение с погрешностью и сравнение с допуском

`docs/measurement.md:14-39`: у измеренной величины есть статус
`measured | unavailable(reason)`, численная ошибка `numeric_error` и
неопределённость модели `model_uncertainty`. Последняя выводится из допусков
граней и рёбер и из фактических отклонений приближений.

Две величины сравниваются с допуском (`measurement.md:683-751`):

```
t = e_a + e_b + u_a + u_b + floor · max(|a|, |b|, L^d)
```

`e` — численные ошибки, `u` — неопределённости, `floor` — относительный пол
(у них 1e-9), `L^d` — масштаб тела в нужной степени. Вердикт тройной:
**совпало / не совпало / не ясно**. Тела сопоставляются по измерениям, без
опоры на идентификаторы.

Измерение никогда не влияет на чтение (`architecture.md:110`).

**Для Nonius.** Это готовая теория для двух наших задач:
- беглая форма по сетке против точной по STEP: у сетки большая
  неопределённость (огранка), у STEP — малая. Сейчас поправки на беглую форму
  зашиты константами в `nonius-app/src/intake/shape.rs` (`Limits`);
- сравнение версий: «не ясно» — честный третий ответ, который сейчас
  смешан со «спорным».

## 3. Ограниченное чтение

`docs/decode-resource-caps.md:13-48`, `crates/cadmpeg-core/src/decode/policy.rs:28-71`.
Четыре вида границ:

| Вид | Пример | Что при нарушении |
|---|---|---|
| Инвариант формата | версия контейнера = 4 | файл испорчен |
| На запись | счётчик сверяется с оставшимися байтами **до** выделения памяти | файл испорчен |
| Потолок сессии | всего распаковано ≤ min(8 ГиБ, 16 МиБ + 1000 × размер файла); один кусок ≤ min(2 ГиБ, 16 МиБ + 256 × размер) | отказ всего чтения |
| Локальный бюджет | работа на элемент пропорциональна входу | пропустить элемент, записать потерю |

Арифметика только `checked`; `saturating` как способ ограничения запрещён
(`decode-resource-caps.md:80`).

**Для Nonius.** **Сделано** (PR #27): `nonius-sldprt/src/container/budget.rs`
— те же потолки (секция ≤ 16 МиБ + 256 × файл, всё ≤ 16 МиБ + 1000 × файл),
секция распаковывается один раз. Подробнее —
[sldprt-container.md](sldprt-container.md) §7–8.

## 4. Фазз-тесты

106 целей в `crates/cadmpeg-fuzz/fuzz_targets/`, со словарями и
начальными файлами. Крейт фазза — вне рабочего пространства (nightly).
Правило из `crates/cadmpeg-fuzz/README.md`: найденная поломка становится
обычным unit-тестом через тот же публичный вход. Нехватка памяти на входе в
десятки байт — баг.

**Для Nonius.** Две-три цели: контейнер `.sldprt`, `DisplayLists`,
заголовок STEP. Наш читатель разбирает чужие файлы, которые человек
приносит из любых источников.

## 5. Образцы, золотые файлы, журнал прогонов

- **Корпус с манифестом** (`corpus/README.md`, `corpus/manifest.toml`):
  у каждого образца sha256, лицензия, автор, версия CAD, закреплённые
  выводимые поля.
- **Золотые снимки** (`docs/golden-coverage-floors.toml`): их число на
  кодек может только расти (`AGENTS.md:34`). Перегенерация — одной командой,
  с просмотром разницы. Ожидаемые значения берутся из спецификации, а не из
  вывода упавшего прогона (`AGENTS.md:30`).
- **Журнал прогонов по чужим файлам** (`docs/evaluations.toml`): файлы
  выкладывать нельзя, поэтому записывается только диалект, дата, уровень,
  число файлов и итог — без имён.
- **Открытые образцы NIST** (`corpus/nist-pmi/`, общественное достояние,
  `LicenseRef-NIST-PD`): два `.SLDPRT` SolidWorks 2018 и STEP AP242.
  Годятся в наши тесты.

**Для Nonius.** Журнал вида «прогнали N деталей SW2018–2024: беглая форма
сошлась со STEP в K случаях» — без путей и имён деталей человека.

## 6. Срез для отчёта об ошибке

`docs/repro-bundles.md`: из найденной проблемы вырезается наименьший кусок
модели, тексты обезличиваются, числа геометрии сохраняются, есть сигнатура с
хэшем и полосами ±10 %. На будущее — для отчёта «сравнение ошиблось» от
человека, который не может прислать саму деталь.

## 7. Явные автоматы состояний

`docs/state-machines.md`: неявные автоматы (конвейер перевода, коды выхода,
сессия чтения) описаны таблицами переходов; так нашлись недостижимые и
запрещённые состояния. Для Nonius — «импорт → паспорт → коммит», разбор
папки (беглый план → уточнение → раскладка), `Store::upgrade`.

## 8. Отметка точности у каждого числа

`docs/cad-ir.md:184-191`: `byte_exact` (как в файле), `derived`
(вычислено из прочитанного), `inferred` (догадка по признакам), `unknown`.
Для `meta.yaml` и паспорта: масса «из файла SolidWorks» и масса «по сетке»
— разные по доверию числа.

## 9. Чистый разбор формата (clean-room)

`LEGAL.md:9-50` (с оговоркой, что это не юридическая консультация):

- **Можно:** свои файлы и файлы с правами; наблюдение байтов (hex, энтропия,
  сравнение файлов с контролируемыми правками); публичные документы.
- **Нельзя:** SDK производителя, в том числе заголовки и имена символов;
  декомпиляция программ («смотреть можно выходные файлы, но не
  реализацию»); сведения под NDA; чужие файлы без прав; обход шифрования.
- Кто работал с SDK формата, не пишет его декодер.
- Каждый PR с декодером несёт декларацию происхождения знаний.
- Неизвестное — не в спецификацию, а в файл открытых вопросов с полями
  «Вопрос / Известно / Нужно / Противоречие».

**Для Nonius.** `nonius-sldprt` сделан ровно так: по своим файлам. Стоит
записать это правило явно. COM-экспорт через установленный у человека
SolidWorks — использование программы, а не реверс.

## 10. Если подключать cadmpeg

Ложится на наши точки так:

| Наша точка | Что из cadmpeg |
|---|---|
| `ShapeGlance` | точный B-rep вместо сетки + отчёт о потерях |
| `GeometrySource` | паспорт без STEP |
| `Converter` | `.sldprt` → STEP без SolidWorks |
| `Comparator` | сравнение тел без идентификаторов |
| будущий источник дерева | операции из `.sldprt` (частично) |

Риски: внутренний формат меняется без миграций (версии 8 → 10 за недели,
`AGENTS.md:23`); MSRV 1.88 (у нас 1.85); 25 крейтов и 176 пакетов
зависимостей. Лицензия Apache-2.0 совместима с нашей GPL-3.0-only;
зависимости — MIT / Apache / Zlib / BSD, `hdf5-reader` не проверен.

Вывод: подключать отдельным процессом (`cadmpeg convert/measure --report
JSON`), не линковать.
