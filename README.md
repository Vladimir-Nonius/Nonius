# Nonius

**Контроль версий для CAD-моделей.** Хранит каждую версию деталей и сборок, подсвечивает цветом, что изменилось, и связывает модели с заметками конструктора. Работает с SolidWorks и с любым CAD через STEP. Открытый, бесплатный, делается вместе с людьми и ИИ.

> Нониус — шкала штангенциркуля, которая показывает самые малые различия между двумя положениями. Программа делает то же самое с версиями моделей.

**Статус: ранняя разработка.** Уже работает: проект, импорт STEP/SLDPRT, версии деталей на git + LFS, история, сравнение паспортов версий, откат и выгрузка. Цветная подсветка геометрии и аддин SolidWorks — следующие этапы.

## Зачем

- SolidWorks без серверного PDM не даёт удобной истории версий, а git видит в SLDPRT только «файл изменился».
- Готовые PDM дорогие, закрытые и переносят на механиков ветки программистов.
- Почему сделано именно так — нигде не записывается и теряется.

## Что будет уметь

- **История каждой детали** с превью и описанием изменений; откат к любой версии.
- **Цветная подсветка изменений:** добавленный материал зелёным, убранный красным, сдвинутый жёлтым.
- **Изменения дерева построения:** `D1@Эскиз2: 40 → 45 мм`, «добавлена Фаска1».
- **SolidWorks и любой CAD:** аддин для SolidWorks, остальное через STEP.
- **Совместная работа:** лидер утверждает версии, остальные получают их при синхронизации со ссылкой на скачивание.
- **Заметки как в Obsidian:** `[[кронштейн@v3#Фаска1]]`, обратные ссылки, граф связей.
- **Доступ для ИИ:** MCP, API и командная строка; у агента своя роль и права.
- **Local-first:** проект — обычная папка с открытыми форматами (STEP, YAML, Markdown, git).

## Попробовать

Нужны [Rust](https://rustup.rs) 1.85 или новее, [Git](https://git-scm.com) и [Git LFS](https://git-lfs.com).

```sh
cargo install --path crates/nonius-cli

nonius init мой-станок --name "Станок ЭЭО"
cd мой-станок

nonius import ~/модели/кронштейн.step      # деталь «кронштейн» с model.step
nonius status                              # что изменилось
nonius commit кронштейн -m "Первая версия"  # v1
# ...правите модель, импортируете заново...
nonius diff кронштейн                      # чем текущее отличается от последней версии
nonius commit кронштейн -m "Толщина 4 → 5 мм под новый вал"   # v2
nonius log кронштейн                       # история, новые первыми
nonius diff кронштейн v1 v2                # сравнить две версии
nonius restore кронштейн v1 -m "v2 не подошла"   # v3 = содержимое v1, история цела
nonius export кронштейн v2 ./для-лазера    # выгрузить файлы версии
```

Каждая версия — коммит git, который трогает только папку детали; модели хранятся через Git LFS. Историю видно и в обычном `git log`.

## Устройство

```
crates/
├── nonius-core/   # ядро: формат проекта, схемы файлов, точки расширения, контрактные тесты
├── nonius-store/  # хранилище версий на git + Git LFS
├── nonius-step/   # модуль: чтение заголовка STEP (какая CAD, автор, протокол)
└── nonius-cli/    # командная строка `nonius`
docs/
└── ARCHITECTURE.md
```

Ядро маленькое, всё остальное — модули: источник геометрии, источник дерева, сравнение, отрисовка, экспорт, события, интерфейс. Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
